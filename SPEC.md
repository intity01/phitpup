# ผิดปุ๊บ (PhitPup) — v1 spec

แก้ข้อความที่พิมพ์ผิดภาษา ไทย ⇄ อังกฤษ บน Windows. Minimal, native, local ล้วน (ไม่มีโค้ด network).
Research: https://claude.ai/artifact/5REER2LjL4cjsJ8WekjnPz

## Decisions
| Area | Decision |
|---|---|
| Platform | Windows 10/11 x64 first. Core crate has no OS calls so macOS can follow. |
| Language | Rust, `windows` crate. Core also builds to WASM for the website. |
| Modes | `suggest` (default, changed 2026-10-28: bubble near caret, Tab to accept), `manual`, `auto` (fix on space, opt-in). |
| Hotkey | `Shift+Backspace`. No selection → fix last word; repeat → extend one word back. Selection → convert selection. Press right after a fix → undo. |
| Layouts | Kedmanee + Pattachote, read from installed layouts via `ToUnicodeEx`/`MapVirtualKeyEx`. Any layout pair by design. |
| After fix | Always switch the Windows input language (`WM_INPUTLANGCHANGEREQUEST`). |
| Detection | Thai orthography rules + embedded Thai/English trigram tables. Target exe ~1–2 MB. |
| Injection | `SendInput` + `KEYEVENTF_UNICODE` (backspaces, then new text). Clipboard only to read a selection, restored afterwards. |
| Capture | `WH_KEYBOARD_LL` buffer of the current/recent words, in memory only, cleared on click/focus change/Enter. |
| Settings | Tray menu + `config.toml`. |
| Self-disable | Password fields / password managers, fullscreen games, Remote Desktop. Terminals/IDEs: auto & suggest off, manual still works. |
| Test targets | Chrome/Edge, Word/Notepad, LINE/Discord/Messenger, VS Code. |
| Release | Public GitHub, MIT, unsigned; SHA256 + GitHub Actions build. |
| Website | GitHub Pages, Thai/English: download + SHA256, WASM try-it box, guide + FAQ (SmartScreen, privacy). |

## Milestones
1. ✅ `phitpup-core`: layout tables, convert, round-trip tests (2026-10-28)
   - Tables generated by `cargo xtask gen-layouts` from KBDUS / KBDTH0 / KBDTH1.
   - Pattachote quirks: `\` key has no standard char (Windows gives private-use U+F8C7, dropped);
     `_` and ั each sit on two keys, so Thai→English picks the unshifted key.
2. ✅ Direction detector (rules + trigrams) with a test corpus and false-positive budget (2026-10-28)
   - `thai::check` spelling rules (accepts 99.9% of held-out TNC words; rejects doubled tone marks).
   - Model (`model.bin`, 357 KB): character trigrams from PyThaiNLP TNC freq (CC0) + Hunspell en
     (SCOWL), plus a lexicon of the 10k most frequent Thai words; a lexicon word costs
     min(trigram cost, −log2 freq). `cargo xtask fetch-corpus` → `train-model` →
     `eval-detector [--lexicon N]`.
   - Presets on held-out words (trigrams held out; lexicon from the full list, so Thai recall
     is reported weighted by word frequency):
     | layout | preset | min chars | TH-meant recall (freq) / EN words misread | EN-meant recall / TH misread (freq) |
     |---|---|---|---|---|
     | Kedmanee | `SUGGEST` | 2 | 99.8% / 0.35% | 99.2% / 0.04% |
     | Kedmanee | `AUTO` | 3 | 95.7% / 0.12% | 97.6% / 0.0005% |
     | Pattachote | `SUGGEST` | 2 | 99.5% / 0.51% | 98.1% / 0.08% |
     | Pattachote | `AUTO` | 3 | 89.3% / 0.16% | 92.5% / 0.0006% |
   - The lexicon lifted Pattachote `AUTO` recall from 66.9% to 89.3% (shy→ที่ now flips).
   - Known gaps: English false positives are mostly lowercase acronyms (mvp, gdp, lcd), and
     English recall/false-positive numbers are unweighted because the English list has no
     frequencies. An English frequency tier list (SCOWL sizes) would fix both.
3. ✅ Keyboard hook + manual hotkey + SendInput injection + layout switch (2026-10-28)
   - `phitpup_core::Fixer`: mirrors text before the caret; Shift+Backspace fixes the last word,
     each repeat reaches one word further (max 8), then one more press restores the original.
   - `crates/phitpup` (windows-sys): LL keyboard+mouse hooks on the main thread, fixes on a
     worker thread; layouts read from installed HKLs via `ToUnicodeEx`; edits sent in one
     `SendInput`; injected events tagged `dwExtraInfo = "PPUP"`; layout switched with
     `WM_INPUTLANGCHANGEREQUEST`. Empty buffer → selection via Ctrl+Insert + full clipboard
     snapshot/restore; nothing selected → plain Backspace.
   - Live test in Notepad (2026-10-28), verified by saving and reading the file: last-word fix
     (l;ylfu → สวัสดี) + switch to Thai, 2/3 presses, undo + switch back to English,
     Thai → English (้ำสสน → hello), mixed selection (hello l;ylfu → hello สวัสดี) with the
     clipboard left as it was. Not yet tested: Chrome/Edge, Word, LINE/Discord, VS Code.
   - Bitdefender removed `target\debug\phitpup.exe` and `cargo.exe` during testing (keyboard
     hook + SendInput + clipboard reads like a keylogger) and likely killed the process tree.
     Dev needs an antivirus exclusion for the project folder; releases need code signing and
     false-positive submissions to AV vendors (track in milestone 7). Never work around AV.
   - Selection converts only the words the detector is sure about at `AUTO` thresholds
     (`Detector::selection`); if none qualify the whole selection flips.
   - The old `target/` folder kept files the antivirus had locked; `.cargo/config.toml` builds
     into `target-fresh/` until `target/` can be deleted.
   - Chrome/Edge, VS Code, LINE, Discord need a manual pass: the computer-use tool cannot type
     into browsers or IDEs, Word is not installed, and chat apps would mean typing into real
     chats. Checklist + code-point viewer: `testing/manual-test.html`.
   - Risks to check live: apps that delete a whole Thai cluster per Backspace (Chrome?),
     Ctrl+Insert not copying in some apps (LINE?), Shift released by selection path.
4. ✅ Tray icon + `config.toml` + self-disable rules (2026-10-28, code done; manual pass pending)
   - No console (`windows_subsystem = "windows"`); one copy per sign-in (named mutex);
     errors and "already running" shown in a message box; first run shows a tray balloon.
   - Tray (own thread): icon drawn at runtime (white ผ on blue, grey when paused); left click
     pauses; menu: pause, manual/suggest, start with Windows (HKCU `Run`), open settings, quit.
   - `%APPDATA%\PhitPup\config.toml` (`phitpup_core::config`, a flat TOML subset): `mode`,
     `off_in_fullscreen`, `off_apps`, `quiet_apps`. Bad lines keep defaults and are reported;
     the tray rewrites only the `mode` line; edits apply within 2 s without a restart.
   - `context::gate` per key: **off** (keys untouched, nothing remembered) when paused, in
     password fields, password managers, credential prompts, remote desktop / VM viewers,
     full-screen windows, `off_apps`; **quiet** (no bubble) in terminals and code editors and
     `quiet_apps`. Password fields: Win32 `ES_PASSWORD` plus UI Automation `IsPassword` on a
     focus-watcher thread (`SetWinEventHook`), which assumes "password" until it knows.
   - UI Automation through hand-written COM vtable calls (`uia.rs`, slots checked against the
     SDK's `UIAutomationClient.h`) instead of the `windows` crate. Also gives the bubble the
     caret in apps that draw their own (TextPattern2 caret range) before the mouse fallback.
   - Smoke test: starts, writes the settings template, a second copy refuses to start. Tray
     menu, UIA password detection and caret placement in Chrome/Discord still need a manual pass.
   - Not yet: configurable hotkey, auto mode (`mode = "auto"` falls back to suggest).
5. ✅ Suggest bubble (layered window at caret) (2026-10-28, done before 4)
   - `Fixer::suggestion` judges the word being typed at `SUGGEST` thresholds; `Fixer::accept`
     applies it only if the text still ends with that word at a word boundary.
   - `--suggest` flag (until `config.toml`): bubble under the caret with the fixed word and a
     "Tab" hint; Tab accepts (and switches layout), Esc dismisses until the word ends. Never
     takes focus or clicks; per-monitor DPI; hidden in standard `Edit` password boxes.
   - Caret from `GetGUIThreadInfo`; apps that draw their own caret (Chrome, Electron) fall
     back to the mouse pointer until UI Automation lands in milestone 4.
   - Confirmed working by the user (2026-10-28).
   - Polish (2026-10-28): bubble drawn per pixel (anti-aliased squircle-ish card, soft shadow,
     hairline border, grayscale text) and shown with `UpdateLayeredWindow`; fades/slides in,
     glides, stays put along a word, waits 120 ms of quiet before first showing; light/dark
     theme; TH/EN badge. Shift+Backspace right after Tab undoes the accepted fix.
   - Previews without a live desktop: `cargo test -p phitpup preview -- --ignored`.

### Logo (2026-10-28)
- Chosen after four rounds: a big white **p** on a coral squircle; turned upside down the same
  shape reads as Thai **ป** (typing on the "wrong side"); the dark bar is the text cursor.
  Rejected: letter-on-square (too plain), puppy mascot (says nothing about the app).
- Drawn from geometry in `phitpup_core::icon` (no image files in the build): the tray renders
  it at the exact system size (grey when paused); `build.rs` writes a `.res` with sizes
  16–256 that the MSVC linker embeds; `cargo xtask icons` exports `assets/icon/` (ICO, PNGs,
  SVG). PNG/ICO/RES writers are dependency-free.

### Settings window (2026-10-28)
- Clicking the tray icon (or starting PhitPup again while it runs) opens a native settings
  window; the tray menu keeps the quick switches (Settings…, pause, mode, start with Windows,
  quit). Pages: **General** (on/off, mode, start with Windows, full screen, settings file),
  **Programs** (add from running programs; per program "Off" or "No bubble"; built-in lists
  explained), **Words** (never suggested; Shift+Esc on the bubble adds the word), **Shortcuts**
  (fix hotkey and accept key are changeable; Esc / Shift+Esc fixed).
- Drawn by hand like the bubble (per-pixel shapes + ClearType GDI text), Windows 11 Settings
  colours in light/dark, coral accent, per-monitor DPI, dark title bar. Fonts: Segoe UI Variable,
  falling back to Segoe UI; each face is checked after creation because a broken font registry
  can hand back the italic. Previews: `cargo test -p phitpup window_preview -- --ignored`.
- New settings keys: `ignore_words`, `hotkey`, `accept_key` (`phitpup_core::hotkey`: names like
  `"ctrl+shift+space"`; keys that type a character need Ctrl or Alt). Every change is saved at
  once; edits made by hand in the file are still picked up within 2 s.
- PhitPup is off in its own windows, so shortcuts can be recorded there.
- Bubble badge now uses the logo coral; its key hint shows the configured accept key.
- Live check (2026-10-28): second start opens the window in front, dark theme, 876×639 at 100%.
  Clicking through the pages, the program picker and typing words still need a manual pass.
