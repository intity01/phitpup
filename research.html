ตลาดมีเยอะ แต่ไม่มีตัวที่ “เล็ก + ครบเฉพาะที่จำเป็น”

ฝั่งไทยมีสองขั้ว ขั้วแรกคือ RightType และ typeThai ที่ฉลาดมาก (มีพจนานุกรม 60k คำ หรือโมเดลจำแนก) แต่ฟีเจอร์ล้น ทั้ง snippet, คณิตศาสตร์, ฝึกพิมพ์, AI rewrite ขั้วที่สองคือ PimPid, GaeKai, keyboard-lang-fixer ที่เล็กจริง (150–180 KB) แต่พึ่ง clipboard, รองรับแค่เกษมณี และไม่ตรวจว่าทิศทางถูกหรือไม่

ของเก่าอย่าง RightLang, LangOver, แปลพิมพ์เพลิน หยุดพัฒนาไปตั้งแต่ปี 2557–2561 ส่วนต่างชาติส่วนใหญ่ทำคู่ รัสเซีย/ฮีบรู/อาหรับ ⇄ อังกฤษ และ Microsoft ปิดคำขอฟีเจอร์นี้ใน PowerToys ไปแล้ว

Reddit และ Facebook: ค้นแล้วไม่เจอเธรดที่ตรงประเด็นผ่านเครื่องมือค้นหา (Facebook กลุ่มส่วนใหญ่ค้นจากภายนอกไม่ได้) ข้อมูลส่วนใหญ่จึงมาจาก GitHub, Store และ Thaiware

4 ส่วนที่ทุกตัวต้องตัดสินใจ

1 · เอาข้อความมา

Capture

  • Clipboard: ส่ง Ctrl+C / Ctrl+Insert แล้วอ่าน (GaeKai, PimPid) ง่ายแต่ทับ clipboard ผู้ใช้
  • Keyboard hook buffer: WH_KEYBOARD_LL เก็บคำล่าสุดในหน่วยความจำ (RightType, PimPid) ไม่ต้องเลือก
  • UI Automation / Accessibility: อ่านข้อความรอบเคอร์เซอร์ตรง ๆ (RuSwitcher บน mac)
2 · แปลง

Map

  • ตารางตายตัว เกษมณี ⇄ QWERTY (ส่วนใหญ่)
  • ToUnicodeEx + MapVirtualKeyEx อ่านจาก layout ที่ติดตั้งจริง ได้ปัตตะโชติ/มนูญชัยฟรี (keyboard-lang-fixer)
  • ต้องจัดการ Shift, CapsLock, ตัวที่กด Shift แล้วได้เลขไทย
3 · ตัดสินใจ

Detect

  • ไม่ตรวจ: ผู้ใช้กดเอง กลับทิศเมื่อกดซ้ำ
  • กฎอักขรวิธีไทย: สระบน/ล่าง/วรรณยุกต์ต้องตามพยัญชนะ (GaeKai)
  • พจนานุกรม / n-gram: RightType, Punto
  • โมเดลจำแนก: typeThai, LuemPreanParSar
4 · ใส่กลับ

Inject

  • Paste แล้วคืน clipboard (ช้า ~400ms, บางแอปเห็นเป็น paste)
  • SendInput + KEYEVENTF_UNICODE: Backspace n ครั้งแล้วพิมพ์ใหม่ (Word อาจกิน/เพิ้ยน)
  • สลับภาษาต่อด้วย WM_INPUTLANGCHANGEREQUEST
  • ปิดตัวเองในช่องรหัสผ่าน, เกม, RDP
ข้อเสนอเบื้องต้น

ตัวที่ minimal + native + local ควรหน้าตาแบบนี้

  • exe เดี่ยว ไม่ต้องติดตั้ง เป้าหมาย < 300 KB, ไม่มี runtime เพิ่ม, ไม่ต้องสิทธิ์ admin, ไม่มีโค้ด network เลย
  • ปุ่มเดียวทำสองอย่าง: มีข้อความเลือกอยู่ = แปลงที่เลือก, ไม่มี = แปลงคำล่าสุดจาก hook buffer, กดซ้ำ = ย้อนกลับ
  • แมปจาก layout ที่ติดตั้งจริง ผ่าน ToUnicodeEx ได้เกษมณี/ปัตตะโชติ/มนูญชัยโดยไม่ต้องเขียนตาราง
  • ตรวจทิศทางด้วยกฎอักขรวิธีไทย + bigram อังกฤษเล็ก ๆ ไม่ต้องมีพจนานุกรมใน v1
  • tray icon + ไฟล์ config ข้อความ แทนหน้าต่างตั้งค่า
  • เว็บโปรเจกต์บน GitHub Pages พร้อมตัวลองแปลงบนเว็บ (ใช้แกนเดียวกันคอมไพล์เป็น WASM ได้ถ้าเลือก Rust)

ภาษาที่เข้ากับเป้าหมาย: Rust (windows-rs, ได้ WASM ฟรี, ไฟล์ ~200–400 KB) หรือ C/C++ Win32 ล้วน (เล็กสุด ~50–150 KB) หรือ C# + csc ในเครื่อง (~150 KB แต่พึ่ง .NET Framework ที่ติดมากับ Windows)

คำถามที่ใช้ตั้งสเปก

ถามครบ 5 รอบแล้ว คำตอบสรุปอยู่ในตารางด้านบน

ขอบเขตและแพลตฟอร์ม

  1. Windows อย่างเดียวก่อน หรือต้อง macOS / Linux ด้วย
  2. Windows 10 และ 11 ทั้งคู่ หรือ 11 อย่างเดียว, x64 อย่างเดียวหรือ ARM64 ด้วย
  3. ใช้เองคนเดียว แจกเพื่อน หรือปล่อยสาธารณะ / ขึ้น Microsoft Store

พฤติกรรมหลัก

  1. Manual อย่างเดียว, มี suggest, หรือต้องมี auto ด้วย
  2. ปุ่มลัดที่อยากได้ (Shift+Backspace แบบ RightLang, Ctrl+Shift+Space, double-Shift, CapsLock)
  3. แก้แค่คำล่าสุด, ทั้งประโยค/บรรทัด, หรือเฉพาะที่เลือก
  4. หลังแปลงให้สลับภาษาแป้นพิมพ์ให้ด้วยไหม
  5. ต้องมี undo ไหม (กดซ้ำย้อนกลับ)

ภาษาและแป้น

  1. เกษมณีอย่างเดียว หรือปัตตะโชติ / มนูญชัยด้วย
  2. เฉพาะไทย ⇄ อังกฤษ หรือเผื่อคู่ภาษาอื่น
  3. เลขไทย, สัญลักษณ์ (฿ ๆ ฯ) และ Shift layer จัดการยังไง

เทคนิค

  1. ภาษาที่ใช้เขียน: Rust, C/C++, C#, Zig, หรือให้เลือกให้
  2. ยอมใช้ clipboard ไหม หรือต้องไม่แตะ clipboard เลย
  3. ใส่ข้อความกลับแบบ paste หรือ SendInput
  4. ขนาดไฟล์เป้าหมาย และยอมรับ dependency ได้แค่ไหน
  5. มีหน้าต่างตั้งค่า GUI หรือแค่ tray + ไฟล์ config

ความปลอดภัยและความเป็นส่วนตัว

  1. รายชื่อแอปที่ต้องปิดตัวเอง (password manager, เกม, terminal, RDP)
  2. เซ็นโค้ดไหม (SmartScreen จะเตือนถ้าไม่เซ็น)
  3. ต้องมี auto-update ไหม (ขัดกับ “ไม่มี network”)

เว็บ, ชื่อ, และการปล่อย

  1. ชื่อโปรแกรมและโทนแบรนด์
  2. เว็บ GitHub Pages ต้องมีอะไร: หน้าดาวน์โหลด, ตัวลองแปลงบนเว็บ, คู่มือ, ภาษาไทย/อังกฤษ
  3. ใบอนุญาต (MIT, Apache, GPL)
  4. ชื่อ repo GitHub และใช้บัญชีไหน, ต้องมี GitHub Actions build release ไหม
  5. เกณฑ์ “เสร็จ” ของ v1 และการทดสอบ (แอปไหนต้องผ่าน: Word, Chrome, LINE, Discord, VS Code)
