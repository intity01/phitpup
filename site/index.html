ติดตั้งในหนึ่งนาที

  1. ดาวน์โหลดตัวติดตั้ง

    PhitPup-Setup.exe ติดตั้งให้เฉพาะบัญชีของคุณ ไม่ต้องใช้สิทธิ์ admin มีใน Start menu และถอนออกได้จาก Settings ของ Windows

    ดาวน์โหลดรุ่นล่าสุด

    SHA-256: —

    หรือใช้แบบไฟล์เดียวไม่ต้องติดตั้ง (phitpup.exe)

  2. เปิดตัวติดตั้ง

    ถ้าขึ้นหน้าต่างสีน้ำเงิน "Windows protected your PC" ให้กด More info แล้ว Run anyway เพราะโปรแกรมยังไม่ได้ซื้อใบรับรองแบบเสียเงิน จากนั้นกด Next จนจบ

  3. เริ่มพิมพ์

    ไอคอน p สีส้มจะอยู่ข้างนาฬิกา คลิกเพื่อเปิดหน้าตั้งค่า เลือกโหมด และเปิดให้ทำงานพร้อม Windows อัปเดตรุ่นใหม่ได้จากในแอป

คำถามที่พบบ่อย

ทำไมโปรแกรมแอนตี้ไวรัสถึงเตือน?

ผิดปุ๊บต้องเห็นปุ่มที่คุณกดเพื่อรู้ว่าพิมพ์อะไรไป และต้องพิมพ์คำที่แก้แล้วแทนคุณ ซึ่งเป็นวิธีเดียวกับที่โปรแกรมดักคีย์บอร์ดใช้ แอนตี้ไวรัสบางตัวจึงเตือนแบบเหมารวม โค้ดทั้งหมดเปิดให้ตรวจ และคุณเช็กได้ว่าไฟล์ที่ได้ตรงกับที่ GitHub build ไว้ โดยเทียบค่า SHA-256 ด้านบน

SmartScreen บอกว่าไม่รู้จักผู้พัฒนา ปลอดภัยไหม?

ข้อความนี้ขึ้นกับทุกโปรแกรมที่ไม่ได้ซื้อใบรับรอง code signing ไฟล์ทุกรุ่นถูก build บน GitHub Actions จากโค้ดที่เปิดเผย พร้อมค่า SHA-256 ให้ตรวจ

ถ้ามันแก้คำที่ฉันตั้งใจพิมพ์?

กด Shift+Backspace ทันทีเพื่อคืนคำเดิม ถ้าคำไหนถูกทักบ่อย เช่น ชื่อร้านหรือตัวย่อ ให้คลิก ไม่ต้องแก้ บนฟอง หรือกด Shift+Esc คำนั้นจะไม่ถูกทักอีก หรือเพิ่มเองในหน้า Words

เล่นเกมอยู่จะกวนไหม?

ไม่กวน ผิดปุ๊บปิดตัวเองในหน้าต่างเต็มจอ และเพิ่มโปรแกรมที่ไม่อยากให้ทำงานได้ในหน้า Programs

มีสำหรับ macOS หรือมือถือไหม?

ตอนนี้มีแค่ Windows แกนหลักของโปรแกรมแยกออกจากส่วนที่ผูกกับระบบปฏิบัติการไว้แล้ว รุ่น macOS จึงเป็นไปได้ในอนาคต

ลบโปรแกรมยังไง?

เปิด Settings ของ Windows ไปที่ Apps > Installed apps เลือก PhitPup แล้วกด Uninstall ถ้าใช้แบบไฟล์เดียว ให้ปิด Start with Windows คลิกขวาที่ไอคอน เลือก Quit แล้วลบไฟล์ phitpup.exe การตั้งค่าอยู่ใน %APPDATA%\PhitPup ลบโฟลเดอร์นั้นได้เลย
