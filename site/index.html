พิมพ์ผิดภาษา?
แก้ได้ในปุ๊บเดียว

ลืมกดเปลี่ยนภาษาจนได้ l;ylfu ใช่ไหม ผิดปุ๊บดูออกว่าคุณตั้งใจพิมพ์ สวัสดี แล้วแก้ให้ทันที ไม่ต้องลบพิมพ์ใหม่

ดาวน์โหลดฟรี ลองในเว็บก่อน

ติดตั้งง่าย ไม่ต้องใช้สิทธิ์ admin · ประมาณ 2.5 MB · โอเพนซอร์ส MIT

พรุ่งนี้ว่างไหม

THสวัสดีTab

ลองพิมพ์ดู

พิมพ์ภาษาไทยโดยที่คีย์บอร์ดยังเป็นภาษาอังกฤษ (หรือกลับกัน) ในช่องนี้ ทุกอย่างทำงานในเบราว์เซอร์ของคุณเอง ไม่มีอะไรถูกส่งออกไป

THTab

bubble จะขึ้นระหว่างพิมพ์ กด Tab เพื่อรับ Esc เพื่อซ่อน · Shift+Backspace แก้คำล่าสุดหรือข้อความที่เลือก

ตัวอย่าง:

เลือกได้ว่าจะให้ช่วยแค่ไหน

Tab

แนะนำขณะพิมพ์

bubble เล็ก ๆ ขึ้นใต้เคอร์เซอร์เมื่อคำที่พิมพ์ดูผิดภาษา กด Tab ถ้าใช่ ไม่ใช่ก็พิมพ์ต่อไปเลย เป็นค่าเริ่มต้น

Space

แก้อัตโนมัติ

กด Space แล้วคำที่ผิดจะถูกแก้ให้เอง แต่เฉพาะคำที่มั่นใจมาก ถ้าแก้ผิด กด Shift+Backspace ทันทีเพื่อคืนคำเดิม

ShiftBackspace

เมื่อกดปุ่มลัด

แก้คำล่าสุด กดซ้ำเพื่อย้อนไปทีละคำ หรือเลือกข้อความแล้วกดเพื่อแก้ทั้งก้อน ใช้ได้ทุกโหมด

  • แก้แล้วสลับภาษาของคีย์บอร์ดให้ด้วย พิมพ์ต่อได้เลย
  • รองรับแป้นเกษมณีและปัตตะโชติ
  • ใช้ได้ในเกือบทุกโปรแกรม: เบราว์เซอร์, LINE, Discord, Word, Notepad
  • ปิดตัวเองในช่องรหัสผ่าน, โปรแกรมจัดการรหัสผ่าน, Remote Desktop และเกมเต็มจอ

สิ่งที่คุณพิมพ์ ไม่ออกจากเครื่อง

ตัวโปรแกรมที่เห็นปุ่มที่คุณกดไม่มีโค้ดต่ออินเทอร์เน็ตเลยแม้แต่บรรทัดเดียว จะมีแค่ตัวอัปเดตแยกต่างหากที่ต่อเน็ต และต่อเฉพาะตอนคุณกด "Check for updates" เพื่อถามเลขรุ่นล่าสุดและโหลดตัวติดตั้ง การตัดสินว่าคำไหนผิดภาษาทำด้วยตารางสถิติขนาดเล็กที่อยู่ในตัวโปรแกรม จำข้อความไว้แค่คำที่กำลังพิมพ์ ลืมทันทีเมื่อคลิกหรือสลับหน้าต่าง และโค้ดทั้งหมดเปิดให้ตรวจได้

ติดตั้งใน 1 นาที

  1. ดาวน์โหลดตัวติดตั้ง

    PhitPup-Setup.exe ติดตั้งให้เฉพาะบัญชีของคุณ ไม่ต้องใช้สิทธิ์ admin มีใน Start menu และถอนออกได้จาก Settings ของ Windows

    ดาวน์โหลดรุ่นล่าสุด

    SHA-256: —

    หรือใช้แบบไฟล์เดียวไม่ต้องติดตั้ง (phitpup.exe)

  2. เปิดตัวติดตั้ง

    ถ้าขึ้นหน้าต่างสีน้ำเงิน "Windows protected your PC" ให้กด More info แล้ว Run anyway เพราะโปรแกรมยังไม่ได้ซื้อใบรับรองแบบเสียเงิน จากนั้นกด Next จนจบ

  3. เริ่มพิมพ์

    ไอคอน p สีส้มจะอยู่ข้างนาฬิกา คลิกเพื่อเปิดหน้าตั้งค่า เลือกโหมด และเปิดให้ทำงานพร้อม Windows

คำถามที่พบบ่อย

ทำไมโปรแกรมแอนตี้ไวรัสถึงเตือน?

ผิดปุ๊บต้องเห็นปุ่มที่คุณกดเพื่อรู้ว่าพิมพ์อะไรไป และต้องพิมพ์คำที่แก้แล้วแทนคุณ ซึ่งเป็นวิธีเดียวกับที่โปรแกรมดักคีย์บอร์ดใช้ แอนตี้ไวรัสบางตัวจึงเตือนแบบเหมารวม โค้ดทั้งหมดเปิดให้ตรวจ และคุณเช็กได้ว่าไฟล์ที่ได้ตรงกับที่ GitHub build ไว้ โดยเทียบค่า SHA-256 ด้านบน

SmartScreen บอกว่าไม่รู้จักผู้พัฒนา ปลอดภัยไหม?

ข้อความนี้ขึ้นกับทุกโปรแกรมที่ไม่ได้ซื้อใบรับรอง code signing ไฟล์ทุกรุ่นถูก build บน GitHub Actions จากโค้ดที่เปิดเผย พร้อมค่า SHA-256 ให้ตรวจ

ถ้ามันแก้คำที่ฉันตั้งใจพิมพ์?

กด Shift+Backspace ทันทีเพื่อคืนคำเดิม ถ้าคำไหนถูกเตือนบ่อย เช่น ตัวย่อ ให้กด Shift+Esc ตอนที่ bubble ขึ้น คำนั้นจะไม่ถูกเตือนอีก หรือเพิ่มเองในหน้า Words

เล่นเกมอยู่จะกวนไหม?

ไม่กวน ผิดปุ๊บปิดตัวเองในหน้าต่างเต็มจอ และเพิ่มโปรแกรมที่ไม่อยากให้ทำงานได้ในหน้า Programs

มีสำหรับ macOS หรือมือถือไหม?

ตอนนี้มีแค่ Windows แกนหลักของโปรแกรมแยกออกจากส่วนที่ผูกกับระบบปฏิบัติการไว้แล้ว รุ่น macOS จึงเป็นไปได้ในอนาคต

ลบโปรแกรมยังไง?

เปิด Settings ของ Windows ไปที่ Apps > Installed apps เลือก PhitPup แล้วกด Uninstall ถ้าใช้แบบไฟล์เดียว ให้ปิด Start with Windows คลิกขวาที่ไอคอน เลือก Quit แล้วลบไฟล์ phitpup.exe การตั้งค่าอยู่ใน %APPDATA%\PhitPup ลบโฟลเดอร์นั้นได้เลย
