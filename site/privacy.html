สรุป

ผิดปุ๊บไม่ส่งสิ่งที่คุณพิมพ์ไปที่ไหนเลย ไม่มีบัญชีผู้ใช้ ไม่มีโฆษณา ไม่มีการเก็บสถิติการใช้งาน และเราไม่ได้รับข้อมูลใด ๆ ของคุณ

สิ่งที่ผิดปุ๊บเห็นขณะทำงาน

เพื่อรู้ว่าคุณพิมพ์ผิดภาษา ผิดปุ๊บต้องเห็นปุ่มที่คุณกด มันจำไว้แค่ข้อความก่อนเคอร์เซอร์ (ไม่เกิน 300 ตัวอักษร) ในหน่วยความจำ และลืมทันทีเมื่อคุณคลิก สลับหน้าต่าง หรือย้ายเคอร์เซอร์ ข้อความนี้ไม่ถูกบันทึกลงดิสก์และไม่ถูกส่งไปไหน ผิดปุ๊บไม่ทำงานเลยในช่องรหัสผ่าน โปรแกรมจัดการรหัสผ่าน หน้าต่างเข้าสู่ระบบของ Windows และ Remote Desktop

ตอนคุณสั่งแก้ข้อความที่เลือกไว้ ผิดปุ๊บคัดลอกข้อความนั้นผ่านคลิปบอร์ด แล้วคืนสิ่งที่อยู่ในคลิปบอร์ดเดิมให้ทันที

สิ่งที่บันทึกในเครื่อง

  • ไฟล์ตั้งค่า %APPDATA%\PhitPup\config.toml: โหมด ปุ่มลัด โปรแกรมที่ให้ปิด และคำที่คุณเพิ่มหรือที่ผิดปุ๊บเรียนรู้จากการแก้ของคุณ
  • วันที่เตือนอัปเดตครั้งล่าสุด และเลขรุ่นที่เปิดล่าสุด (เพื่อบอกว่ามีอะไรใหม่หลังอัปเดต)
  • ถ้าเปิด "เปิดพร้อม Windows": ค่าใน Registry ที่ชี้ไปที่โปรแกรม

ลบได้ทั้งหมดโดยถอนการติดตั้งแล้วลบโฟลเดอร์ %APPDATA%\PhitPup

การต่ออินเทอร์เน็ต

ตัวโปรแกรม phitpup.exe ไม่มีโค้ดต่ออินเทอร์เน็ต มีแค่ตัวอัปเดต phitpup-update.exe ที่แยกไว้ ซึ่งทำงานเฉพาะตอนคุณกด "เช็กอัปเดต" มันขอไฟล์ release.json จาก intity01.github.io เพื่อดูเลขรุ่นล่าสุด และถ้าคุณกดติดตั้ง ก็โหลดตัวติดตั้งจาก github.com คำขอเหล่านี้ไม่มีข้อมูลของคุณ แต่ GitHub ในฐานะผู้ให้บริการเว็บจะเห็นที่อยู่ IP ของคุณ ตามนโยบายของ GitHub

การแจ้งปัญหา

ปุ่ม "แจ้งปัญหา" คัดลอกรุ่นของโปรแกรม รุ่นของ Windows แป้นพิมพ์ และการตั้งค่า (รายการคำบอกแค่จำนวน) ไปที่คลิปบอร์ด แล้วเปิดหน้า GitHub คุณเป็นคนวางและส่งเอง ผิดปุ๊บไม่ส่งอะไร

เว็บไซต์นี้

เว็บนี้อยู่บน GitHub Pages ไม่มีคุกกี้ ไม่มีตัวติดตาม ช่องทดลองพิมพ์ทำงานในเบราว์เซอร์ของคุณเท่านั้น ภาษาที่เลือกจำไว้ในเบราว์เซอร์ของคุณ

Privacy policy

PhitPup (ผิดปุ๊บ) by Intity01 · sukudone.team-dev · applies to version 0.3.2 and later · last updated 29 October 2026

In short

PhitPup never sends what you type anywhere. There are no accounts, no ads and no usage statistics, and we receive no data about you.

What PhitPup sees while it runs

To notice text typed in the wrong layout, PhitPup has to see the keys you press. It keeps only the text before the cursor (at most 300 characters) in memory and forgets it as soon as you click, switch windows or move the cursor. That text is never written to disk or sent anywhere. PhitPup does nothing at all in password fields, password managers, Windows sign-in prompts and Remote Desktop.

When you ask it to fix selected text, PhitPup copies that text through the clipboard and puts back what was on the clipboard right away.

What is saved on your computer

  • The settings file %APPDATA%\PhitPup\config.toml: mode, shortcuts, programs to stay out of, and words you added or PhitPup learned from your corrections.
  • The date of the last update reminder, and the version that last ran (to show what's new after an update).
  • If "Start with Windows" is on: a registry value pointing at the program.

Uninstall and delete the %APPDATA%\PhitPup folder to remove all of it.

Internet connections

phitpup.exe has no networking code. Only the separate updater, phitpup-update.exe, goes online, and only when you click "Check for updates": it asks intity01.github.io for release.json to learn the newest version number and, if you click install, downloads the installer from github.com. These requests carry nothing about you, though GitHub, as the host, sees your IP address under GitHub's own policy.

Reporting a problem

"Report a problem" copies the program version, Windows version, keyboard layouts and settings (word lists as counts only) to the clipboard and opens GitHub. You paste and send it yourself; PhitPup sends nothing.

This website

This site is hosted on GitHub Pages and uses no cookies and no trackers. The try-it box runs in your browser only. The language you pick is remembered in your browser.
