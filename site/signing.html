Code signing policy

นโยบายการเซ็นโค้ดของผิดปุ๊บ (PhitPup) · ปรับปรุงล่าสุด 31 ตุลาคม 2026

ผิดปุ๊บขอใช้บริการเซ็นโค้ดฟรีสำหรับโอเพนซอร์สจาก SignPath Foundation เมื่อได้รับอนุมัติ ไฟล์ที่ออกจะเซ็นด้วยใบรับรองของ SignPath Foundation: Free code signing provided by SignPath.io, certificate by SignPath Foundation

อะไรถูกเซ็น

เฉพาะ phitpup.exe, phitpup-update.exe และ PhitPup-Setup.exe ที่ GitHub Actions สร้างจากซอร์สโค้ดใน github.com/intity01/phitpup ตอนติด tag รุ่นใหม่ ไม่มีการเซ็นไฟล์ที่สร้างในเครื่องของใคร

ทีม

  • ผู้เขียนโค้ด (Committers and reviewers): Intity01
  • ผู้อนุมัติการเซ็น (Approvers): Intity01

โค้ดที่คนนอกทีมเสนอมา ต้องผ่านการตรวจของทีมก่อนรวม ทุกคนในทีมใช้การยืนยันตัวตนหลายขั้น (MFA) ทั้งบน GitHub และ SignPath

ความเป็นส่วนตัว

ผิดปุ๊บไม่ส่งข้อมูลไปที่ไหน ยกเว้นตอนคุณกด "เช็กอัปเดต" ตัวอัปเดตจะถามเลขรุ่นล่าสุดจาก intity01.github.io และโหลดตัวติดตั้งจาก github.com ถ้าคุณกดติดตั้ง ดูรายละเอียดที่นโยบายความเป็นส่วนตัว

Code signing policy

PhitPup (ผิดปุ๊บ) · last updated 31 October 2026

PhitPup has applied for free open-source code signing from SignPath Foundation. Once approved, releases are signed with its certificate: Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

Only phitpup.exe, phitpup-update.exe and PhitPup-Setup.exe as built by GitHub Actions from the source at github.com/intity01/phitpup when a release is tagged. Nothing built on anyone's own computer is signed.

Team roles

  • Committers and reviewers: Intity01
  • Approvers: Intity01

Changes proposed by anyone outside the team are reviewed by a team member before they are merged. Every team member uses multi-factor authentication on GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user: when you click "Check for updates", the updater asks intity01.github.io for the newest version number and, if you choose to install, downloads the installer from github.com. See the privacy policy.
